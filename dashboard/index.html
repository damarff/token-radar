How the radar scores a protocol

Implied value follows only from the snapshot's own figures. No protocol name is ever special-cased; the same formula scores every row, and each row's detail view shows its own numbers.

base = TVL × 0.25
growth = clamp(7-day change, −60%, +150%)
growth multiplier = 1 + growth × 0.75 while capital flows in, × 0.9375 while it flows out
maturity multiplier = 0.6 + min(age, 1,095 days) ÷ 1,095 × 0.4
implied value = base × growth multiplier × maturity multiplier

The base multiple of 0.25 is the share of locked value a launch would price: a protocol's token is worth a fraction of the value it holds, not the whole of it. Growth matters because capital flowing in is the best signal a launch is near — and a falling TVL is weighted harder than a rising one, because farmers leave before a token that never comes. Age matters because a protocol that has run for years with no token has survived the cycles a launch has to survive. A protocol listed under 90 days ago, or one whose listing date is unknown, is treated with the neutral 365-day age.

What the model cannot see: audits, team, points programs, and whether a token is even planned. Treat the implied value as a ranking signal, not a price target — and never farm more than you can afford to lose.
